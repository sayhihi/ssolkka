# 쏠까 (ssolkka) - 기능과 유저 플로우

"오늘 커피 누가 쏠까". 팀에서 커피 쏠 사람을 운세로 정하는 모바일 웹 게임.
한 폰에 다 같이 손가락을 올리면 손가락 수만큼 카드가 생기고, 각자 자기 카드를 뒤집어 운세 점수를 본다.
운이 제일 좋은 사람이 "오늘 베푸는 사람"으로 당첨된다. 당첨은 벌칙이 아니라 축하.
이름 입력도 캐릭터 선택도 없다. 색과 번호로만 자기를 구분한다.

## 구성 (Vercel)

- Next.js App Router 한 프로젝트. 화면은 `/`(손가락 올리기 = 시작), `/r`(뽑기, 결과).
- 저장소 없음. DB 없음, 로그인 없음. 게임 상태는 URL 쿼리에 전부 담고, 링크를 연 쪽에서 재계산한다.
- 점수는 `버전|시드|번호` 해시로 결정. 시드는 게임마다 하나, URL에 기록. 같은 링크면 어디서 열어도 같은 카드.
- `lib/fortune.ts`의 `FORTUNE_VERSION`. 계산식이나 규칙을 바꾸면 버전을 올리고 옛 버전은 남긴다(과거 링크 보호).
- OG 이미지 라우트 `/api/og`(예정). 결과 링크 미리보기 카드를 요청 시점에 그린다. 유일한 서버 코드.
- 배포: GitHub main 푸시 = Vercel 자동 배포. 도메인은 기본 vercel.app.

## 두 가지 모드

| | 손가락 모드 | 뽑기 모드 |
|---|---|---|
| 인원 | 2~5명 (아이폰 동시 터치 한계) | 2~10명 |
| 시작 | 다 같이 손가락 올리고 2초 유지 → 카운트다운 3,2,1 | "한 명씩 뽑기" 버튼 |
| 시드 생성 | 카운트다운 끝나는 순간 | 뽑기 모드 진입 순간 |
| 카드 | 손가락 수만큼 뒷면으로 깔림. 각자 자기 카드 탭 | 더미 탭마다 한 장씩 나와 바로 뒤집힘 |
| 끝 | 마지막 카드가 뒤집히면 | "끝" 버튼 (2장 이상) |

둘 다 상단에 "지금 1등: 3번 72점". 내 차례에 넘을지가 긴장 포인트.
번호별 점수는 시드로 미리 정해져 있어서 뽑기 모드에서 먼저 뽑든 나중에 뽑든 유불리가 없다.

## 점수와 등급

- 점수 0~100 정수. 같은 해시에서 숨은 소수점(0~9)을 하나 더 뽑아 동점일 때만 공개한다. 가위바위보 화면 없음.
- 등급 3단계. **대길 = 그 판의 당첨자 한 명에게만 붙는 라벨.** 길은 50점 이상, 평은 미만. 1등이 아니면 95점이어도 길.
- 대길 메시지 풀은 전부 "베푸는 날" 톤. `{name}`은 이름이 있으면 이름, 없으면 "3번". `{day}`는 요일.
- 요일 이벤트(v2): 월요일 전원 -5, 금요일 전원 +8. 시작 화면에서 끌 수 있다.
- 당첨 규칙은 "제일 높은 사람" 하나. 낮은 사람 옵션은 대길 라벨과 모순이라 뺐다.
- 메뉴 운세는 v1 보류.

## URL (`lib/game-url.ts`)

| 키 | 뜻 |
|---|---|
| v | 계산 로직 버전 |
| m | 모드. f(손가락) / d(뽑기) |
| s | 시드 (게임마다 랜덤) |
| n | 카드 수. 뽑기 모드는 뽑은 장수 |
| d | 날짜 YYYY-MM-DD (KST). 요일 이벤트와 표시용 |
| e | 요일 이벤트. 0이면 끔 (기본 켬) |
| x | 뽑기 모드에서 "끝" 눌렀음 |
| l | 이름 라벨, 선택. `번호:이름` 쉼표 구분 |

점수와 당첨자는 넣지 않는다. 링크 연 쪽에서 다시 계산하니까 위조할 수 없다.
뽑기 모드는 뽑을 때마다 URL을 갱신해서 중간에 새로고침해도 같은 게임이 복원된다.
재굴림은 가능하지만 한 폰 모드는 다 같이 보고 있어서 눈치가 막는다.

## 유저 플로우

### 손가락 모드
1. 시작 화면. "다 같이 손가락 올려". 손가락마다 색 원과 번호. 각자 자기 색을 기억.
2. 2명 이상이 2초 유지하면 카운트다운. 손가락이 늘거나 줄면 리셋.
3. 카운트 끝 → 카드 n장이 뒷면으로 깔림 (디자인 후: 손가락 자리에서 격자로 날아가 정렬).
4. 각자 자기 카드를 탭. 순서 자유. 마지막 한 장이 남으면 한 박자 쉬고.
5. 결과. 당첨자 크게, 전원 리스트 점수순. 당첨자 이름 적기(선택). 링크 복사.

### 뽑기 모드
1. 시작 화면 하단 "한 명씩 뽑기".
2. 더미 탭 → 카드 한 장. 번호는 뽑은 순서, 색은 순환. 최대 10장.
3. 2장 이상이면 "끝" 버튼 → 결과.

### 공유 링크를 받은 사람
1. 링크를 열면 같은 시드로 같은 카드. 손가락 모드 링크는 카드가 뒷면이라 직접 뒤집어 볼 수 있고, 뽑기 모드 링크는 결과가 바로 보인다.
2. 재택이나 떨어진 팀은 이걸로 서버 없이 원격 참여. 진행자가 "오늘 5명" 손가락 모드 링크를 던지면 각자 자기 번호를 확인.
3. "다시 하기"로 새 게임.

## 예정 (디자인 확정 후)
- Motion: 손가락 원 숨쉬기, 원 → 카드 정렬 애니메이션, 카드 뒤집기, 숫자 카운터, 마지막 카드 흔들림.
- canvas-confetti 당첨 순간. use-sound 카운트다운 완료음, 카드 소리 (진동 API는 아이폰 사파리 불가).
- 카드 길게 눌러 이름 붙이기.
- 결과 이미지 저장(html-to-image), 카카오 공유, `/api/og`.
- 메시지 풀 등급당 30개.

## v2 후보
- 색마다 픽셀 캐릭터 매핑 (카드 앞면에 자리 비워둠).
- 면제권, 역전 카드. 지난 당첨자 보호.
- 슬랙 봇. 커피 장부(결과 링크 모아 집계).

## 구현 메모
- 손가락 패드는 포인터 이벤트로 pointerId별 추적. `touch-action: none`, 뷰포트 확대 금지.
- Next 16 린트 `react-hooks/set-state-in-effect`: effect 본문에서 setState 금지. 타이머 콜백 안은 괜찮다.
- `cacheComponents` 켜짐. `/r`은 `useSearchParams`를 쓰는 클라이언트 컴포넌트를 Suspense로 감싼다.
