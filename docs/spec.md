# 쏠까 (ssolkka) - 기능과 유저 플로우

"오늘 커피 누가 쏠까". 팀에서 커피 쏠 사람을 운세로 정하는 모바일 웹 게임.
한 폰에 다 같이 손가락을 올리면 손가락 수만큼 카드가 생기고, 각자 자기 카드를 뒤집어 운세 점수를 본다.
운이 제일 좋은 사람이 "오늘 베푸는 사람"으로 당첨된다. 당첨은 벌칙이 아니라 축하.
이름 입력도 캐릭터 선택도 없다. 색과 번호로만 자기를 구분한다.

## 구성 (Vercel)

- Next.js App Router 한 프로젝트. 화면은 `/`(손가락 올리기 = 시작), `/r`(뽑기, 결과).
- 저장소 없음. DB 없음, 로그인 없음. 게임 상태는 URL 쿼리에 전부 담고, 링크를 연 쪽에서 재계산한다.
- 점수는 `버전|시드|번호` 해시로 결정. 시드는 게임마다 하나, URL에 기록. 같은 링크면 어디서 열어도 같은 카드.
- `lib/fortune.ts`의 `FORTUNE_VERSION`. 계산식이나 규칙을 바꾸면 버전을 올리고 옛 버전은 남긴다(과거 링크 보호).
- OG 이미지 라우트 `/api/og`(예정). 결과 링크 미리보기 카드를 요청 시점에 그린다. 유일한 서버 코드.
- 배포: GitHub main 푸시 = Vercel 자동 배포. 도메인은 기본 vercel.app.

## 두 가지 모드

| | 손가락 모드 | 뽑기 모드 |
|---|---|---|
| 인원 | 2~5명 (아이폰 사파리 동시 터치 한계). 초과 터치는 토스트로 안내: 6번째 터치가 들어오는 기기는 거부, 아이폰처럼 전부 취소되는 기기는 취소 순간에 안내 | 2~10명 |
| 시작 | 다 같이 손가락 올리고 2초 유지 → 카운트다운 3,2,1 | "한 명씩 뽑기" 버튼 |
| 시드 생성 | 카운트다운 끝나는 순간 | 뽑기 모드 진입 순간 |
| 공개 | 화면 전환 없이 **손가락 자리 그대로** 점수 낮은 순으로 하나씩 튀어나오고 마지막이 당첨자. 손 올린 동안 원 안에서 캐릭터 8종이 슬롯머신처럼 돌다가 자기 색 동물로 멈춤 | 하단 **부채꼴** 뒷면 카드 10장 중 직접 한 장 탭. 위로 올라와 뒤집히고 목록에 점수순으로 쌓임 |
| 끝 | 당첨자 공개 후 "결과 자세히" 버튼으로 결과 화면(공유용) | "끝" 버튼 (2장 이상) |

- 손가락 모드 링크(`/r?m=f`)는 바로 결과 화면. 카드 목록 화면은 없다.
- 뽑기 모드는 **번호는 뽑은 순서, 운은 집은 자리**. 부채꼴 카드는 전부 똑같은 뒷면이라 자리는 보이지 않고, 점수는 `hash(버전|시드|자리)`. 첫 번째로 뽑은 사람이 1번 빨강 여우.
- 뽑기 모드 상단에 "1등 72점" 배지. 내 차례에 넘을지가 긴장 포인트.

## 점수와 등급

- 점수 0~100 정수. 같은 해시에서 숨은 소수점(0~9)을 하나 더 뽑아 동점일 때만 공개한다. 가위바위보 화면 없음.
- 등급 3단계. **대길 = 그 판의 당첨자 한 명에게만 붙는 라벨.** 길은 50점 이상, 평은 미만. 1등이 아니면 95점이어도 길.
- 문구는 `lib/messages.ts`. 문체는 친구가 톡으로 던지는 반말, 짧게 끊기. 앞 조각(어떤 운이 좋은지 구체적으로) + 뒤 조각(커피 결론)을 따로 뽑아 조합. 등급당 30 × 8. `{name}님`은 이름이 있으면 이름, 없으면 "3번". `{day}`는 요일.
- 대길 뒤 조각은 전부 "베푸는 날" 톤. 풀을 바꾸면 옛 링크의 문구는 바뀔 수 있다. 점수와 당첨자는 안 바뀌므로 허용.
- 요일 이벤트(v2): 월요일 전원 -5, 금요일 전원 +8. 해당 요일에만 시작 화면에 ON/OFF 토글이 보이고 끌 수 있다.
- 당첨 규칙은 "제일 높은 사람" 하나. 낮은 사람 옵션은 대길 라벨과 모순이라 뺐다.
- 메뉴 운세는 v1 보류.

## URL (`lib/game-url.ts`)

| 키 | 뜻 |
|---|---|
| v | 계산 로직 버전 |
| m | 모드. f(손가락) / d(뽑기) |
| s | 시드 (게임마다 랜덤) |
| n | 손가락 모드: 인원 수. 뽑기 모드: 집은 자리를 뽑은 순서대로 (예: `7,3,1` → 1번=자리7 점수) |
| d | 날짜 YYYY-MM-DD (KST). 요일 이벤트와 표시용 |
| e | 요일 이벤트. 0이면 끔 (기본 켬) |
| x | 뽑기 모드에서 "끝" 눌렀음 |
| l | 이름 라벨, 선택. `번호:이름` 쉼표 구분 |

점수와 당첨자는 넣지 않는다. 링크 연 쪽에서 다시 계산하니까 위조할 수 없다.
뽑기 모드는 뽑을 때마다 URL을 갱신해서 중간에 새로고침해도 같은 게임이 복원된다.
재굴림은 가능하지만 한 폰 모드는 다 같이 보고 있어서 눈치가 막는다.

## 유저 플로우

### 손가락 모드
1. 시작 화면. "다 같이 손가락 올려". 손가락마다 색 원과 번호, 원 안에서 캐릭터 슬롯머신.
2. 2명 이상이 2초 유지하면 카운트다운. 손가락이 늘거나 줄면 리셋.
3. 카운트 끝 → 원이 그 자리에 고정되고 손을 떼도 됨. 점수 낮은 순으로 0.45초 간격으로 **원 안에** 점수가 들어가고(캐릭터는 작아짐, 등급 스티커는 원 테두리), 마지막 당첨자 원이 커지며 금색 + 대길 + 컨페티. 원 바깥에는 아무것도 붙이지 않아 손가락 위치와 무관하게 겹치지 않는다.
4. 하단 고정 카드에 당첨자의 번호, 색, 캐릭터, 점수, 등급, 문구. **원을 탭하면 그 사람 운세로 바뀜.** 아래 "결과 자세히" → 결과 화면. 대기 중에도 하단 200px은 손가락을 받지 않는다(카드 자리).

### 뽑기 모드
1. 시작 화면 우상단 "카드뽑기".
2. 하단 부채꼴에서 아무 카드나 탭 → 위 목록에 점수순으로 쌓임. 번호는 뽑은 순서. 최대 10장.
3. 2장 이상이면 "끝, 누가 쏘나" → 결과(컨페티). 결과 목록 행 탭하면 문구 펼침.

### 공유 링크를 받은 사람
1. 링크를 열면 같은 시드로 같은 카드. 손가락 모드 링크는 카드가 뒷면이라 직접 뒤집어 볼 수 있고, 뽑기 모드 링크는 결과가 바로 보인다.
2. 재택이나 떨어진 팀은 이걸로 서버 없이 원격 참여. 진행자가 "오늘 5명" 손가락 모드 링크를 던지면 각자 자기 번호를 확인.
3. "다시 하기"로 새 게임.

## 구현 메모
- 컨페티는 `app/Confetti.tsx`. canvas-confetti 기본 인스턴스(body 캔버스 + 웹워커)는 아이폰 사파리에서 페이지 전환 직후 안 그려지는 경우가 있어, 트리 안 캔버스에 `useWorker: false`로 직접 그린다. 마운트 시 1회.
- 손가락 패드는 포인터 이벤트로 pointerId별 추적. `touch-action: none`, 뷰포트 확대 금지.
- Next 16 린트 `react-hooks/set-state-in-effect`: effect 본문에서 setState 금지. 타이머 콜백 안은 괜찮다.
- `cacheComponents` 켜짐. `/r`은 `useSearchParams`를 쓰는 클라이언트 컴포넌트를 Suspense로 감싼다.
