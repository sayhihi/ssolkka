# 디자인 프롬프트 (claude.ai/design 용)

와이어프레임과 비주얼을 따로 나누지 않고, 산출물 순서만 단계로 나눈다.
흐름이 흔들리는 화면은 손가락 올리기와 뽑기 둘뿐이라 그 둘만 로파이로 먼저 본다.

```
[제품]
"오늘 커피 누가 쏠까" - 팀에서 커피 쏠 사람을 운세로 정하는 모바일 웹 게임.
한 폰에 다 같이 손가락을 올리면 손가락 수만큼 카드가 생기고, 각자 자기 카드를 뒤집어
운세 점수를 본다. 운세가 제일 좋은 사람이 "오늘 베푸는 사람"으로 당첨된다.
당첨은 벌칙이 아니라 축하다. 결과는 링크와 이미지 카드로 공유한다.
이름 입력도 캐릭터 선택도 없다. 색과 번호로만 자기를 구분한다.

[사용 환경]
- 모바일 전용. 기준 폭 390px, 세로 모드만.
- 점심 먹고 서서 한 폰을 여러 명이 둘러싸고 쓰는 상황. 멀리서도 보이게 크고 굵게.
- 로그인 없음, 입력 없음. 첫 화면에서 10초 안에 카드가 깔려야 한다.

[무드]
- 게임형. 동적이고 발랄하고 약간 뻔뻔한 느낌. 가챠 뽑기나 아케이드 결과 화면의 들뜸.
- 운세지만 점집 느낌은 금지. 사주 톤이 아니라 "오늘의 뽑기" 톤.
- 참고 결: 닌텐도 파티 게임 UI, 뽑기 캡슐 머신, 편의점 이벤트 스티커.
- 피할 것: 보라색 그라데이션, 글래스모피즘, 기본 SaaS 느낌의 회색 카드, 얇은 선 아이콘.

[색과 타이포]
- 바탕은 흰색. 색은 참가자 색이 다 가져간다.
- 참가자 색 8종. 서로 멀리서도 확실히 구분되고 이름 부르기 쉬운 색(빨강, 파랑, 노랑, 초록, 보라, 주황, 분홍, 하늘). 이 8색이 곧 캐릭터 자리라 손가락 원, 카드 앞뒤, 결과 리스트에 일관되게 쓰인다.
- 당첨 연출용 포인트 색 하나(금색 또는 주황), 액션 버튼용 하나.
- 운세 등급 3단계(대길, 길, 평)마다 스티커 느낌의 라벨. 대길은 그 판의 당첨자 한 명에게만 붙는다.
- 제목은 두껍고 둥근 한글 산세리프. 번호와 점수는 크고 과장되게. 번호는 카드에서 제일 큰 요소.
- 본문은 짧은 문장이 대부분이라 가독성보다 리듬감 우선.

[모션 원칙]
- 손가락을 올리면 그 자리에 색 원이 즉시 생기고 숨쉬듯 커졌다 작아진다. 카운트다운 숫자는 화면 중앙에 크게.
- 카운트가 끝나면 원이 카드로 바뀌며 손가락 자리에서 격자로 날아가 정렬된다. 이 순간이 첫 번째 쾌감.
- 카드 뒤집기는 살짝 튀고, 점수는 숫자가 굴러 올라간다. 뽑기 모드는 더미에서 카드가 튀어나오는 느낌.
- 마지막 한 장이 남으면 그 카드가 미세하게 흔들리며 한 박자 쉰다. 당첨 순간에만 컨페티.
- 동점이면 두 카드의 점수 옆에 숨어 있던 소수점이 나타나며 승부가 갈린다. 작은 반전 연출.
- 과한 건 금지. 연출은 정렬과 당첨 두 번, 나머지는 손맛 수준.

[화면 3개]
1. 시작 = 손가락 올리기: 화면 전체가 터치 패드. "다 같이 손가락 올려" 한 줄. 손가락마다 색 원과 번호. 2명 이상 2초 유지 시 카운트다운. 하단에 작은 보조 버튼 "한 명씩 뽑기"(6명 이상용)와 요일 이벤트 토글 하나. 5개 차면 "6명 이상은 뽑기 모드로" 안내.
2. 뽑기: (a) 손가락 모드는 정렬된 카드 n장이 뒷면으로 깔리고 각자 자기 카드를 탭해서 뒤집음. (b) 뽑기 모드는 가운데 카드 더미 하나, 탭하면 한 장이 나와 바로 뒤집히고 아래 줄에 쌓임. 둘 다 상단에 "지금 1등: 3번 72점". 카드를 길게 누르면 이름 붙이기(선택). 뽑기 모드는 2장 이상이면 "끝" 버튼.
3. 결과: 당첨 카드 크게(색, 번호, 이름이 있으면 이름, 점수, 대길 라벨, 운세 한 줄), 아래에 전원 카드 리스트 점수순. 이름 없으면 "이름 적기" 입력 하나. 버튼은 링크 복사, 이미지 저장, 카카오 공유, 다시 하기. 안내 한 줄 "링크를 열면 같은 카드가 보여요".

[컴포넌트]
- 손가락 원(색, 번호, 숨쉬기 상태), 카운트다운 숫자, 운세 카드 앞면/뒷면(색, 번호, 점수, 등급 라벨, 한 줄 메시지, 이름 선택 표시, 동점 소수점),
  카드 더미, 현재 1등 배지, 등급 스티커 라벨 3종, 점수 카운터, 큰 액션 버튼, 작은 보조 버튼, 토글,
  결과 공유 카드(1080x1350 이미지용 별도 레이아웃, 당첨 카드 중심에 전원 색 점 나열).
- 캐릭터 없음. 색 원과 카드 색이 캐릭터 역할. 나중에 색마다 픽셀 캐릭터를 매핑할 수 있게 카드 앞면에 빈 자리 하나.

[산출물 순서]
1. 손가락 올리기, 뽑기 두 화면만 회색 로파이로 먼저. 손가락 올리기는 "손가락 올린 상태"와 "카드로 정렬된 상태" 두 장면, 뽑기는 손가락 모드와 뽑기 모드 각각. 레이아웃 대안 2개씩.
2. 내가 고르면 무드 방향 A(아케이드 뽑기 느낌), B(편의점 이벤트 스티커 느낌) 시안.
3. 무드 확정 후 디자인 시스템(색 8종 포함, 타이포, 간격, 버튼, 카드, 라벨)과 3화면 전체, 공유 이미지 카드.
```
