# 백로그

2026-10-18 기준. 핵심 흐름(손가락 모드, 카드뽑기 모드, 결과, 링크 복사)은 공개 배포됨. 아래는 전부 "있으면 좋은 것".

## 공유
- [ ] **OG 미리보기 카드** `/api/og`. 결과 링크를 카톡이나 슬랙에 붙였을 때 당첨자 카드가 뜨게. 쿼리로 재계산해서 그린다. Vercel `VERCEL_URL` 사용, 환경변수 추가 없음. 시안은 캔버스 Share-Card(1080×1350) 아트보드.
- [ ] **이미지 저장** 버튼 활성화. `html-to-image`로 결과 카드를 PNG로. Share-Card 레이아웃을 별도 컴포넌트로.
- [ ] **카카오 공유** 버튼 활성화. `NEXT_PUBLIC_KAKAO_JS_KEY`(gibyeol 키 재사용 가능), 카카오 개발자 콘솔에 `ssolkka.vercel.app` 플랫폼 도메인 등록 필요. 실패 시 OS 공유 시트 폴백.
- [ ] 링크 복사 시 미리보기 주소(`*-sayhihis-projects.vercel.app`)가 아니라 공개 주소로 바꿔 넣을지 결정. 지금은 공개 주소에서 돌리는 습관으로 해결.

## 게임
- [ ] 카드 길게 눌러 이름 붙이기(카드뽑기 모드, 손가락 모드 원). 지금은 결과 화면에서 당첨자 이름만.
- [ ] 효과음. 손가락 올릴 때 톡, 카운트다운 틱, 완료 딩, 카드 뒤집기, 당첨 팡파르. Web Audio 합성 기본 + 팡파르만 Kenney(CC0). 첫 터치에서 오디오 해제.
- [ ] 손가락 모드 공개 연출 다듬기. 원이 격자로 정렬되는 안(시안 S1→S2)은 보류, 제자리 공개가 확정.
- [ ] 안드로이드에서 손가락 5명 실기기 확인. 부채꼴 겹침 탭 정확도 확인.
- [ ] 문구 풀 다듬기. `lib/messages.ts` 앞 조각 30 × 뒤 조각 8. 어색한 줄 발견 시 교체. 풀이 바뀌면 옛 링크 문구가 바뀔 수 있음(점수·당첨자는 불변).
